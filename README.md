# Portfólio Pessoal - Desenvolvedor Web

## Sobre o Projeto

Este projeto consiste na criação de um **portfólio pessoal em HTML**, desenvolvido durante o curso de **Desenvolvimento de Sistemas do SENAI**.

A página apresenta informações pessoais, habilidades, projetos desenvolvidos e uma área de contato.

## Objetivo

O objetivo da atividade é praticar os principais conceitos de **HTML5**, incluindo:

- Estrutura básica de uma página HTML;
- Tags semânticas;
- Títulos e parágrafos;
- Listas;
- Links;
- Imagens;
- Tabelas;
- Formulários;
- Campos de entrada;
- Navegação interna na página.

## Tecnologias Utilizadas

- HTML5
- CSS3

## Estrutura do Portfólio

O portfólio foi dividido nas seguintes seções:

### Sobre Mim

Apresenta uma breve descrição sobre o desenvolvedor, sua formação e conhecimentos.

Também contém uma imagem de perfil com o dimensionamento de **150x150 pixels**, conforme solicitado na atividade.

### Minhas Habilidades

Lista algumas das habilidades e conhecimentos adquiridos durante o curso:

- HTML5 Semântico
- CSS3 e Responsividade
- Formulários e Validação
- Estruturação de Dados

### Meus Projetos

Apresenta alguns projetos desenvolvidos durante o curso, mostrando:

- Nome do projeto;
- Tecnologias utilizadas;
- Status;
- Link para o projeto no GitHub.

### Entre em Contato

Foi criado um formulário para permitir que visitantes preencham seus dados e enviem uma mensagem.

O formulário possui:

- Nome;
- E-mail;
- Assunto;
- Mensagem;
- Botão para envio.

### Rodapé

O rodapé apresenta informações de contato, incluindo e-mail e telefone.
